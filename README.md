# CUDA 调试信息特殊案例

记录 CUDA → PTX → cubin → 调试器链路中需要特别考虑的案例，供跨阶段调试信息设计和回归验证使用。

## 案例列表

| 编号 | 案例 | 需要特别考虑的问题 | 状态 |
| --- | --- | --- | --- |
| [001](cases/001-shared-object-elimination/README.md) | 第一阶段描述内存位置，第二阶段删除 shared 对象 | 失效位置、删除标记、成员偏移、GPU 地址空间中的有效零偏移 | 已实测（限定工具版本）；处理方案待设计 |

## 记录约定

- 每项分别写明源码、工具版本和编译选项、各阶段产物、调试器实际表现、对照组、结论边界及需要处理的问题。
- 区分实验观察、规范语义和设计建议；不能从输出推断闭源工具内部实现。
- 记录编译器自然产生的案例；若是人工构造或修改中间产物，必须明确标识。
- 未找到的变换保留为待验证问题，不计为已复现案例。

新增案例使用 `cases/NNN-short-name/`，并在本表追加条目。
